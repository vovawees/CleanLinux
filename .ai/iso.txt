LIVE ISO (bootstrap.sh iso; lib.sh iso_check/iso_root/live_config/iso_entry/iso_image/stage_iso; #10)
output: build/ARCH/cleanlinux-ARCH-PROFILE[-spins]-YYYYMMDD.iso + .sha256 (UEFI only, Secure Boot off)
layout: xorriso -as mkisofs -iso-level 3 -joliet -rational-rock -volid CLEANLINUX_YYYYMMDD -partition_offset 16
  -append_partition 2 <ESP GUID> esp.img -appended_part_as_gpt -e --interval:appended_partition_2:all:: -no-emul-boot
  => GPT (p1 = ISO data from 32 KiB, p2 = ESP FAT "CL_EFI") for USB sticks + El Torito EFI image for DVD.
ESP: made by `cleanlinux-boot --root R kernel sync --esp DIR` (EFI/BOOT/BOOTX64.EFI = systemd-boot,
  cleanlinux/KVER/linux + initramfs.img), then its entry is rewritten into loader/entries/
  1-live (quiet) 2-toram (cleanlinux.live.toram) 3-safe-graphics (nomodeset) 4-serial (console=tty0 console=ttyS0,115200);
  loader.conf: default 1-live.conf, timeout 5, editor yes. Initramfs only because R/etc/cleanlinux/initramfs.d/
  10-live.conf has enable=yes (live drivers are built into the kernel: loop sr iso9660 squashfs overlay usb-storage uas).
root=live:LABEL=X (cleanlinux-boot init.c live_root): resolve LABEL via libblkid to ALL matching devices (whole
  stick AND its p1 both carry the iso9660 label), mount RO at /run/cleanlinux/live/medium, first one with
  /cleanlinux/live/rootfs.sfs wins; loop -> /run/cleanlinux/live/rootfs (squashfs|erofs); tmpfs rw; overlay -> /.
  toram copies the image into a tmpfs first (needs 1/0.7 of its size free). cleanlinux.live.image= overrides path.
system image: mksquashfs R rootfs.sfs -comp zstd -Xcompression-level 15 -b 1M -all-root -no-xattrs, run under
  unshare -r (reads 0600 files). README.txt at the ISO root.
live root (iso_root + live_config): ROOTFS copy (with base-devel: ISO_BASE_DEVEL=1 runs stage native first) +
  DISK_PACKAGES (linux systemd-boot cleanlinux-install iwd nano) + ISO_PACKAGES (linux-firmware wireless-regdb) + spins; FIRMWARE="ISO_FIRMWARE" appended to R/etc/burn/burn.conf
  BEFORE installing (buildid includes FIRMWARE -> distinct package from a full linux-firmware);
  package cache copied to R/var/cache/burn/packages (burn clone source); empty root password; hostname
  cleanlinux-live; fstab only tmpfs /tmp; boot.d: dhcpcd + iwd; /etc/dinit.d/getty and serial-getty override the
  cleanlinux-boot services with agetty --autologin root; /root/.bash_profile runs `cleanlinux-setup --auto` (only on
  the main console = last console= of the kernel, i.e. tty1 normally, ttyS0 with the serial entry; once per boot:
  /run/cleanlinux-setup.exit); /etc/motd hints.
