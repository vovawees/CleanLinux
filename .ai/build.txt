BOOTSTRAP (bootstrap/bootstrap.sh + lib.sh)
stages: toolchain | base | native | image | disk | live | all (iso = old alias of live). Steps: step NAME FUNC -> subshell, log
build/ARCH/logs/NAME.log, stamp build/ARCH/stamps/NAME (rerun resumes). WORK=build/ARCH: tools/ rootfs/ src/ obj/
host burn: bootstrap/host-burn.sh builds the release pinned by the burn recipe into build/host.
burn() wrapper = host burn -R RECIPES -p PROFILE --target TRIPLE -j JOBS. Sources cache: build/cache/sources,
packages: build/cache/packages/NAME-VER-REL-ARCH-BUILDID.pkg.tar.zst (BURN_CACHE=build/cache).
toolchain: 00-host-check 01-rootfs-skeleton 10-binutils 20-gcc-pass1 30-linux-headers 40-glibc 50-gcc-final
  60-gcc-runtime 70-toolchain-test 75-toolchain-clean (deletes build trees). base: 80-base (burn install base).
disk: 94-disk-native 95-disk-check 96-disk-root 97-disk-image. live: (native first if LIVE_BASE_DEVEL=1 and no
  base-devel) 94-disk-native 95-live-check 96-live-root 97-live-image (stamps of live are removed at every run).
  --spin DIR|URL (repeatable) adds spin layers; --arch x86_64|aarch64; -j N.
TIMINGS x86_64 on the 2-CPU sandbox (no KVM): toolchain ~65 min (gcc-final ~20, gcc-pass1 ~18), base ~85 min,
  native (base-devel) ~70 min, kernel (linux, VIDEO_CARDS amd intel nouveau virgl) ~60-90 min, live image ~2-10 min.
  aarch64 on the VPS (4 cores, -j 4): toolchain ~37 min, base ~52 min (3133 s), native ~33 min, kernel ~40 min
  (2389 s), live image ~2 min. Spin labwc natively (76 packages incl. mesa without LLVM: softpipe fallback, gtk3): see status.txt.
disk: ~20 GB needed; sandbox has 32 GB total (19 GB free after toolchain).
host tools used: mkfs.btrfs 6.13+ (or the rootfs's own via disk_tool), mtools, dosfstools, sfdisk, unshare -r, python3
  (bootstrap/layer.py), qemu-system-x86_64 / qemu-kvm aarch64 (TCG),
OVMF /usr/share/edk2/ovmf/OVMF_CODE.fd + OVMF_VARS.fd, python3 jinja2 + pyelftools (systemd-boot build).
run long builds in tmux: sandbox cleanlinux_x86 (toolchain base -> /data/cl/logs/x86_64-toolchain-base.log),
  cleanlinux_x86q (/data/cl/queue-x86.sh: waits for EXIT= there, then live --spin -> /data/cl/logs/x86_64-spin.log,
  then tests/live.py). VPS: tmux cleanlinux_a64spin runs /home/opc/ai_workspace/cleanlinux/run-a64-spin2.sh
  (git pull of the 3 repos, live --spin, copy to img/, tests/live.py -> logs/a64-spin*.log).
TESTS: tests/live.py IMAGE [--arch] (install from the live image, see live.txt), tests/boot.py IMAGE,
  tests/install.py IMAGE (disk image: cleanlinux-install --target), tests/layer.sh (bootstrap/layer.py),
  tests/kernel-config.sh linux-X.tar.xz [PROFILE..], tests/smoke.sh, tests/rolling.sh, tests/native-repro.sh.
  tools/check.sh [--quick]: shellcheck, python syntax, doc links, profiles (run before every push).
