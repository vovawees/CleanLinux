RELEASE PROCEDURE (component repos burn / cleanlinux-boot / cleanlinux-install)
1 bump VERSION in Makefile, make check, commit, tag vVER, push (with the tag)
2 make dist  -> NAME-VER.tar.gz (git archive of the tag vVER, gzip -n; cleanlinux-install >= 0.8.1 archives the tag)
3 release vVER via ~/gh.sh POST /repos/vovawees/REPO/releases + upload the tarball (uploads.github.com); notes in Russian
4 CleanLinux-Recipes: packages/NAME/recipe version= + sha256=, tools/readme.sh --write, tools/check.sh, commit, push
helpers in the sandbox home (NOT in repos, recreate when the sandbox resets): ~/gh.sh METHOD PATH [json] (REST + POST /graphql),
tokens in ~/.secrets/ (never in a repo), ~/.git-credentials. git user vovawees <vovawees@gmail.com>.
Release assets: POST https://uploads.github.com/repos/vovawees/REPO/releases/ID/assets?name=FILE (Content-Type
application/octet-stream), limit 2 GiB per asset.
